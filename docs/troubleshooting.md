# Усунення проблем

## Збірка

| Симптом | Причина й рішення |
|---|---|
| `Sketch too big` / `text section exceeds available space` | Стандартний розділ замалий. Tools → **Partition Scheme: Huge APP (3MB No OTA/1MB SPIFFS)**. Перевірте в повідомленні, що `Maximum is` близько 3 145 728 байтів. |
| `lv_image_dsc_t`, `LV_COLOR_FORMAT_*`, `LV_IMAGE_HEADER_MAGIC` не оголошені | У проєкті LVGL 8.3, а картинка експортована у форматі LVGL 9. Видаліть усі старі файли експорту, у SquareLine вкажіть LVGL 8.3.11 і експортуйте заново. |
| `LV_FONT_MONTSERRAT_xx undeclared` / `lv_font_montserrat_xx` не знайдено | Увімкніть цей розмір шрифту в `lv_conf.h`. |
| LVGL не бачить налаштувань (шрифти, глибина кольору) | `lv_conf.h` має лежати в `Документи/Arduino/libraries/` **поруч** із папкою `lvgl`, і на початку має бути `#if 1`. |
| `ui_... was not declared` | Імена віджетів у SquareLine не збігаються з макросами `W_*` / `D_*` у скетчі. Змініть макроси під ваші імена. |
| Помилки про відсутній `ui_ScreenDash` | У проєкті немає екрана «Панель»: поставте `ENABLE_DASH 0` або створіть екран за [docs/software.md](software.md). |
| `... in archive is not an object` | Пошкоджений кеш збірки. Закрийте IDE й видаліть `C:\Users\<імʼя>\AppData\Local\arduino\sketches`. Додайте цю папку у винятки антивіруса. |
| Помилка `'SomeType' was not declared` у прототипі функції | Arduino сама вставляє прототипи перед першою функцією. Описуйте власні типи (`enum`, `struct`), які використовуються в параметрах функцій, **вище** за першу функцію. |
| Помилки `esptool` або пошкоджений пакет плат | Видаліть пакет esp32 у Boards Manager і встановіть заново. |
| Дивні помилки зі шляхом | Не тримайте проєкт у шляху з пробілами та довгими вкладеннями. |

## Прошивка й запуск

| Симптом | Рішення |
|---|---|
| Serial Monitor порожній | Tools → **USB CDC On Boot: Enabled**, швидкість 115200. |
| Не прошивається | Відключіть buck-конвертер (живлення має бути лише з USB), перевірте кабель (потрібен із даними). |
| Плата не стартує після живлення | Не тримайте BOOT при подачі живлення (GPIO9 вмикає режим завантаження). |
| Екран чорний або «сміття» | Перевірте піни SCL/SDA/CS/DC/RST за таблицею, живлення 3.3 V, а також `LV_COLOR_16_SWAP 0` в `lv_conf.h` і Depth 16 bit в експорті. |
| Постійно `SEARCH 500k` / `SEARCH 250k` | Авто не відповідає: запалювання вимкнено; CANH/CANL переплутано; трансивер не 3.3 V; немає спільної землі. Перевірте утилітою [`tools/pidscan`](../tools/pidscan/pidscan.ino). |

## Дані

| Симптом | Рішення |
|---|---|
| Параметра немає в списку | Авто його не підтримує. У Serial Monitor рядок `Supported PIDs: ...` показує, що підтримується. |
| `--` замість значення | Авто не відповідає на цей PID (або відповідь старша за 3 с). |
| Невелика затримка температури й boost | Це нормально: температура опитується раз на секунду, boost ділить шину з обертами та швидкістю. Інтервали можна змінити в таблиці `PARAMS` і масиві `ints` функції `pollDash`. |
| Затримка обертів | Подивіться в Serial Monitor `rate=` (відповідей за секунду) і `reply=` (скільки авто відповідає). Для порівняння спробуйте `WIFI_AUTOSTART 0` або `ENABLE_WIFI 0`. |

## Wi-Fi

| Симптом | Рішення |
|---|---|
| Мережі `Gauge` не видно | Wi-Fi не ввімкнено: утримайте BOOT 4 с (на екрані `WI-FI ON`). Піднесіть телефон ближче: антена SuperMini слабка. Спробуйте знизити `WIFI_TX_POWER`. |
| Підключився, а сторінка не відкривається | Вимкніть мобільні дані; вводьте `http://192.168.4.1` (не https). Деякі телефони питають, чи залишатися в мережі без інтернету: погодьтесь. |
| Wi-Fi вимкнувся сам | Спрацювало автовимкнення `WIFI_IDLE_MS`. Поставте 0, щоб вимкнути цю поведінку. |
| Не вдається створити мережу | Пароль `WIFI_PASS` має містити щонайменше 8 символів. |
